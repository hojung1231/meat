# 이븐 스테이크

두께 3cm 소고기를 원하는 굽기에 맞춰 이븐하게 굽는 게임입니다. 화면 연출이 아니라 열전달 계산 결과로 고기가 익습니다. 팬과 도마를 몇 번이든 오갈 수 있어서, 짧게 굽고 쉬기를 반복하는 그릴 수비드로 회색 띠 없이 굽는 연습을 할 수 있습니다.

## 휴대폰에 설치

**안드로이드 앱 (APK)**

1. 휴대폰에서 [even-steak.apk 내려받기](https://github.com/hojung1231/meat/releases/download/android/even-steak.apk)
2. 내려받은 파일을 열고 설치합니다. 처음이면 "출처를 알 수 없는 앱 설치"를 브라우저(또는 파일 앱)에 허용해야 합니다.
3. 새 버전도 같은 링크에서 받아 그대로 설치하면 기존 앱 위에 업데이트됩니다.

**웹 앱 (아이폰 포함)**

[hojung1231.github.io/meat](https://hojung1231.github.io/meat/) 를 열고 브라우저 메뉴에서 "홈 화면에 추가"를 누릅니다. 한 번 연 뒤에는 오프라인에서도 열립니다.

## 화면과 조작

화면 전체가 조리대입니다. 위쪽에 도마, 가스레인지 위에 팬이 있고(가로로 돌리면 왼쪽 도마, 오른쪽 팬), 고기는 실시간 열전달 계산에 따라 색이 변합니다. 비스듬히 내려다보는 시점이라 고기 옆면이 보이고, 익은 띠가 팬 쪽에서 올라오는 모습을 그대로 볼 수 있습니다.

| 동작 | 방법 |
| --- | --- |
| 뒤집기 | 고기를 톡 누르기, 또는 아래 **뒤집기** |
| 팬 ↔ 도마로 옮기기 | 고기를 끌어서 놓기, 또는 아래 **팬에 올리기 / 도마로** |
| 불 세기 0~10 | 아래 슬라이더, −/+ 버튼 |
| 기름 두르기 | 아래 **기름** |
| 버터 베이스팅 | 팬 위에서 **버터**를 누르고 있는 동안 |
| 자르고 채점 | 도마 위에서 **자르기** |
| 시간 배속 1·4·16·32·64× | 왼쪽 위 배속 버튼을 누를 때마다 바뀜 |
| 일시정지 | 왼쪽 위 ‖ 버튼, 또는 안드로이드 뒤로 가기 |

오른쪽 위 **힌트 구슬**을 누르면 그 정보가 열립니다. 다시 누르거나 × 를 누르면 닫힙니다.

| 구슬 | 내용 |
| --- | --- |
| 중심 온도 | 탐침 온도계 값, 목표까지 남은 온도, 중심 온도 기록 그래프 |
| 온도계 | 팬, 고기 윗면(일반인은 아랫면도) 온도 |
| 고기 옆면 | 옆면을 펼쳐 본 그림 |
| 단면 투시 | 지금 잘랐을 때의 단면 |
| 열화상 | 셀마다 현재 온도 |
| 두께별 온도 | 두께 방향 현재/최고 온도와 회색 띠 기준선 |
| 굽기 기록 | 면별 팬 접촉 시간, 뒤집기·팬에 올린 횟수, 팬/도마 시간 막대 |

## 난이도

| 난이도 | 힌트 구슬 | 말풍선 안내 | 시계 |
| --- | --- | --- | --- |
| 일반인 | 7개 전부 | 전부 | 있음 |
| 말단셰프 | 온도계(팬·윗면), 고기 옆면, 굽기 기록 | 탈 때 같은 위험 경고만 | 있음 |
| 수셰프 | 없음 | 없음 | 없음. 불 세기 숫자도 숨김 |

수셰프는 불꽃, 고기 색, 연기, 지글거리는 소리와 의성어만 보고 굽습니다. 채점 결과 화면은 난이도와 상관없이 단면과 모든 수치를 보여 주고, 최고 점수는 난이도와 목표 굽기별로 따로 기록됩니다.

## 물리 모델 (`www/physics.js`)

- 고기 단면(폭 100mm × 두께 30mm)을 50 × 30 셀로 나눈 2차원 유한체적 열전도. 셀마다 온도, 수분, 최고 도달 온도, 갈변 지수를 계산합니다.
- 수분량에 따라 열전도도와 열용량이 바뀌고, 100°C를 넘는 열은 물을 끓여 날려 크러스트가 안쪽으로 자랍니다.
- 팬은 버너 입력, 대류·복사 손실, 고기로 빠지는 열, 떨어진 육즙의 증발을 계산하는 열용량 덩어리입니다. 무쇠, 3중 스테인리스, 코팅 알루미늄의 무게와 방사율이 다릅니다.
- 공기에 닿은 면의 증발 냉각, 단백질 수축에 의한 육즙 손실, 마이야르 갈변(탄 정도까지)을 계산합니다.

## 채점 (100점)

| 항목 | 배점 | 기준 |
| --- | --- | --- |
| 목표 굽기 | 35 | 가장 덜 익은 층의 최고 온도가 목표 ±1.5°C 이내면 만점 |
| 회색 띠 | 20 | 크러스트 아래 68°C(목표가 높으면 목표 +6°C)를 넘게 익은 층. 2mm 이하 만점, 10mm 이상 0점 |
| 위아래 대칭 | 10 | 같은 깊이의 위아래 최고 온도 차 |
| 크러스트 면 A / B | 각 10 | 갈변 지수 1.2~3.8 만점, 창백하거나 타면 감점 |
| 육즙 | 15 | 중량 손실 12% 이하 만점 |

## 개발

```
npm install
npm test          # 물리 테스트
npm start         # http://localhost:8000  (주소 끝에 #debug 를 붙이면 개발자 도구에서 window.__game 으로 상태 확인)
python3 tools/subset-fonts.py   # 새 한글 문구를 넣었다면 글꼴 다시 만들기
```

글꼴은 주아(Jua)와 검은고딕(Black Han Sans, 둘 다 SIL OFL)을 필요한 글자만 남겨 `www/fonts/` 에 넣었습니다. 앱이 인터넷 없이도 같은 글꼴로 보입니다.

`main` 에 푸시하면 GitHub Actions가 두 가지를 합니다.

- `.github/workflows/android.yml`: Capacitor로 안드로이드 프로젝트를 만들어 APK를 빌드하고 `android` 릴리스의 `even-steak.apk` 를 교체합니다.
- `.github/workflows/pages.yml`: `www/` 를 GitHub Pages에 배포합니다.

`signing/debug.keystore` 는 모든 빌드를 같은 키로 서명해 폰에서 지우지 않고 업데이트되게 하는 개발용 키입니다(비밀번호 `android`). 이 저장소가 공개라면 누구나 같은 키로 서명할 수 있으니, Play 스토어 배포처럼 진짜 서명이 필요하면 별도 키를 GitHub Secrets에 넣어 쓰세요.
